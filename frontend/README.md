# Team Task Manager
A full-stack task management web application where admins can create projects, assign tasks, manage teams, and track progress using role-based access control.

---

## Features
- User Authentication (Signup/Login)
- Role-Based Access Control (Admin/Member)
- Project Management
- Team Member Assignment
- Task Creation & Assignment
- Task Status Tracking
- Dashboard Analytics
- Overdue Task Detection
